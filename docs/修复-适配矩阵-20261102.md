## 1. BUG-03：侧栏两种状态都补到 44px（shell-chrome）

### 改法

`packs/shell-chrome/mobile.css` 把规则从「只认 `[data-open="true"]`」扩成两种状态都覆盖：

```css
/* 展开/停靠态的行内按钮 + 折叠轨道的图标按钮 */
:root:not([data-dsh-adapt="off"]) .dshm-drawer [data-slot="sidebar"] :where(button, [role="button"], a) {
  min-height: 44px !important;
}
/* 展开/停靠态的会话行、项目行：宿主 dsh-client-ui-workspace 的稳定 ARIA 角色 */
:root:not([data-dsh-adapt="off"]) .dshm-drawer [data-slot="sidebar"] [role="treeitem"] {
  min-height: 44px !important;
}
```

- 没有点名任何 `.YDXeBa_*` / CSS Module 哈希类名；`role="treeitem"` 来自
  `dsh-client-ui-workspace/lib/client.js` 里 `SessionNodeItem` / `ProjectRowItem` / `SearchResultItem`
  的 `role: "treeitem"`（稳定 ARIA 契约，不是我们造的标记）。
- **没有宿主门阀**：0.8.1 的 #319 地板以 `[data-slot="main"]` 为根（`lib:507`），**不覆盖侧栏**；
  所以侧栏在 0.8.0 / 0.8.1 上都需要本包。README 已写清这一点。
- opt-out 保留：`:root:not([data-dsh-adapt="off"])`（语义见 §2）。

### 判据（`tools/check-pack.mjs`）

- 内置 fixture 扩成真实结构：`[data-slot="sidebar"]` 内新增折叠轨道按钮（36px，`[data-fixture="rail"]`）
  与两条 `role="treeitem"` 行（32 / 34px）；折叠态隐藏 `.rows`，展开态隐藏 `.rail`。
- `measurePage` 新增 `railButtons`（可见轨道按钮）与 `sidebarTreeitems`（可见停靠行）；
  `sidebarButtons` 改为只取可见元素（隐藏轨道按钮不再产生 0×0 噪声）。
- `validateBaseline`：声明 `shell-hit-target` 的包必须有这两类元素、且基线高度 <44px。
- `checkShellAssertions` 新增 `runtime.shell.rail`、`runtime.shell.dockedRows`；
  `checkOptOut` 与 `checkDesktop` 也逐项比较这两个面。
- 红色回归：`test/checkpack-regression.test.mjs` 新增「把 treeitem 规则重新用 `[data-open="never"]`
  限制 → `runtime.shell.dockedRows` 必须 FAIL」；6/6 通过（先手工跑红）。

### 证据

- t12 修前（平板 0.8.1 真机，旧包）：`32×31 sessionRow`、`34×21 projectRow`、`36×15 rail icon`；
  `shell-chrome` 只抬了 brand/panelRow（`42`/`44`）。
- 修后 fixture：基线 返回栏 25 / 抽屉按钮 28 / 轨道 36 / 停靠行 32 → 全部 **44**；
  `RESULT PASS（24 passed · 0 failed · 4 skipped）`，`--desktop` 通过（含轨道与停靠行零改动）。
- 真机/真实 0.8.1 **未复测**（不装包边界），已写进 catalog `missing`。

## 3. BUG-02：逐类计数 + 定向 switch 命中层试验（我们的空白，不新增通配规则）

### 3.1 真实页逐类计数（2026-11-02，t20 复测）

环境：dsh-mobile **0.8.1** 专用页、390×844、`(pointer: coarse)`、DPR 3；用 dsh-ui-lab 的配对缓存
打开侧栏「Plugins」（settings/plugin 列表页），枚举 `[data-slot="main"]` 内可见控件：

| 类别 | 总数 | <44 | 典型尺寸 |
|---|---|---|---|
| `button[role="switch"]` | **41** | **41** | 36×20，computed `min-height:auto` |
| 其它 `button` / `[role="button"]` | 53 | 0 | 宿主 #319 地板已接管（44） |
| 链接 `a` | 0 | 0 | — |
| 表单 `input/select/textarea` | 0 | 0 | — |
| 其它 | 0 | 0 | — |
| **合计** | **94** | **41** | 与 t12（94/20/41/92）一致 |

方法：复用 dsh-ui-lab `openMobileSurface` + `openPanel('Plugins')`，再点一次侧栏同名行进入列表页，
`page.evaluate` 遍历控件并读 `getBoundingClientRect` / `computedStyle`。计数已写进 `catalog.json`
的 `core-panel.evidence.missing`。

### 3.2 定向命中层试验（合成 fixture，真实 primitive CSS）

fixture 复制 `@deepseek-ai/dsh-client-ui-primitives` 的 Switch（`lib/index.js:3463-3478`、
`lib/Switch.module.css`：36×20、padding 2、轨道=按钮背景、旋钮=子 `span` 16×16），
再加一个「用 `::after` 画旋钮」的第三方开关作为风险对照。规则：

```css
:root:not([data-dsh-adapt="off"]) [data-slot="main"] button[role="switch"] { position: relative !important; }
:root:not([data-dsh-adapt="off"]) [data-slot="main"] button[role="switch"]::after {
  content: ""; position: absolute; inset: -12px; background: transparent;
}
```

| 观测 | 结果 |
|---|---|
| 命中（核心开关） | 加规则前 ±20/24px 的点落在 `DIV.row`；加规则后同四点全部命中 `switch` |
| 视觉 | 开关仍 **36×20**、旋钮仍 **16×16**（`visualUnchanged: true`） |
| 点击语义 | 在扩展后的边缘点 `click()` → `aria-checked` 由 false 变 **true** |
| opt-out | `<html data-dsh-adapt="off">` 后四点全部回到 `DIV.row`，盒子仍是 36×20 |
| **风险对照** | 第三方开关的 `::after`（16×16 红点）被同一规则覆盖成 `top/left:-12px`、`background:transparent` → **旋钮视觉被破坏** |

### 3.3 结论：做 / 不做

- **不做通配规则**：`::after` 命中层对 DSH 核心 Switch 完全可行（视觉不变、命中 44、opt-out 可回落），
  但 `core-panel` 是 `target:null` 的通配包；任何用 `::before/::after` 画轨道/旋钮的第三方开关都会被
  覆盖（风险对照已实测）。`min-height/min-width` 会直接改变核心开关视觉（轨道=按钮背景），
  `padding` + 负 `margin` 依赖每个开关的实现——都不安全。
- **这仍是「我们的空白」，不是「只能上游修」**：外部适配层要在不点名私有类名的前提下做这件事，
  需要宿主提供一个稳定标记（例如设置页行/开关的 `data-dsh-*`）。在此之前，本仓库不改通配层。
- **最小修复建议（上游）**：① 在 `Switch` primitive 内部加透明命中层（该组件没有自有伪元素，
  `::after{inset:-12px}` 即可，天然安全）；② 给设置页插件行加 `data-dsh-*` 稳定标记，让外部 pack
  可以定向；③ 修卡片标题按钮与开关的重叠（t12 竖屏 `hit 88/94`，`top=button.X_2TxG_cardTitle`）。

- **BUG-07**：软键盘/视口项在自动点击下 `focusin` 后立刻 `focusout`，本轮无法用脚本测；需人工真手指复测。
